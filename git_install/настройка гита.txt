git config --global user.name "Ваше Имя"
git config --global user.email "ваш_email@example.com"

git config --list

Регистрируемся на GitHub

Генерация SSH ключей (путь для сохранения по умолнчанию ~/.ssh/id_ed25519)
ssh-keygen -t ed25519 -C "ваш_email@example.com"

Добавьте публичный ключ в настройки GitHub. Зайдите в браузер, откройте settings/keys в профиле на GitHub и добавьте содержимое файла id_ed25519.pub (или другого вашего публичного ключа).
Закрытый ключ (id_ed25519 без расширения .pub) никогда не передавайте посторонним и не вставляйте в код публично — он даёт доступ к вашим репозиториям.
